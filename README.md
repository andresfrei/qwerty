# Qwerty web

The web workspace contains the single Next.js app in `apps/web`.

## Run locally

Use Node.js 26.5.1 and pnpm 11.20.0. Start the app from the repository root:

```sh
pnpm install
pnpm dev
```

Open [https://qwerty.localhost](https://qwerty.localhost). Portless provides the local HTTPS route. The page is a non-indexable placeholder; it is not a product landing page.
